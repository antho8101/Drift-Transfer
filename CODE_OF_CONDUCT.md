# 🌍 Code of Conduct

Drift Transfer is a community project. Please keep discussions respectful, constructive, and focused on making the product better.

## ✅ Expected Behavior

- Be kind and professional.
- Assume good intent.
- Give clear, actionable feedback.
- Respect different levels of experience.
- Keep the project welcoming for contributors and users.

## 🚫 Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Discriminatory language or behavior.
- Publishing private information.
- Spam or intentionally disruptive comments.

## 🛡️ Enforcement

Maintainers may edit, hide, or remove comments, issues, pull requests, or other contributions that do not respect this code of conduct.

If you see a problem, report it privately to the project maintainer.
